# CoinFull Prime 獲利優化與降低虧損計畫

*文件編號：01｜日期：2026-09-16｜資料區間：2021-01-01 ～ 2026-07-31｜基準本金：$1,000*

---

## 1. 起點：為什麼現在是虧的

| 診斷 | 證據（重建） |
|---|---|
| 週轉過高 | 單邊 **1.59 倍/日**，年費用約 **40% / 本金** |
| 毛損益其實為正 | 五年毛損益 **+$1,428**，費用 **−$2,192** → 淨 **−$764（−76.4%）** |
| 因子方向有一項錯了 | taker 買賣壓力因子 IC 為**負**（追價買盤後傾向回落），卻給了 0.35 權重 |
| 動能只看 1 天 | 24 小時漲跌幅在 1 日層級是**均值回歸**，7–14 日才是延續 |
| 沒有風控閘門 | 2023 之後的弱勢市場全程滿倉承受 |

**一句話：不是策略沒有 edge，是成本與參數把 edge 吃光。**

## 2. 三階段優化計畫

### 階段 A：參數修正（預期效益：−76.4% → +154.1%）

| 項目 | 現行 | 建議 | 效益 |
|---|---|---|---|
| 換倉頻率 | 1 日 | **7 日** | 成本 ~40%/年 → ~2.9%/年（單項即讓報酬由負轉正）。1～28 日完整掃描見報告 7.1：7 日非唯一最佳，2/4/8/14 日在統計上無法區分；5 日、10 日顯著較差；14 日可作為低頻替代（成本再省一半，但相位敏感度最高） |
| 多空檔數 | 8 / 8 | **5 / 5** | 集中度提升、週轉下降；K=8 的樣本外 Sharpe 僅 1.18 |
| 動能 | 1 日漲跌幅（0.35） | **0.5×R1d + 0.3×R7d + 0.2×R30d（0.6）** | 樣本外 Sharpe 0.39 → 1.94 |
| 資金費率 | 單點快照（0.20） | **−3 日平均（0.4）** | IC +0.033 → +0.038，訊號更穩 |
| 買賣壓力 | 0.35 | **移除** | 移除後全期 +22.7%（7 日、K=5 測試） |
| 大戶多空比 | 0.10 | 移除 | 無顯著貢獻，省 API 呼叫 |
| 槓桿 | 1.0 | 1.0 | 不加槓桿（先求穩定） |

### 階段 B：風控閘門（預期效益：Sharpe 1.14 → 1.41；OOS 1.06 → 1.94）

| 規則 | 動作 | 全期 Sharpe |
|---|---|---|
| 無閘門 | — | 1.14 |
| **`pts = 0` → 平倉＋停止下單** | 立即平倉 | **1.41** |
| BTC 單日 ≤ −5% | 延後換倉 1 日 | **1.45** |
| 風險結束後延遲 1 日進場 | 延後建倉（可選） | 1.43（回撤 −15.3% → −11.7%） |
| 軟閘門（`pts=0→0.35`；`pts=2` 且**資金費率百分位 45–80** → 1.15） | 部分部位 | 1.35（但總報酬 +202.4%） |

  short_count: 5
  rebalance_days: 7

  momentum:
    mode: blend               # 0.5*R1d + 0.3*R7d + 0.2*R30d

    max_weekly_cost_pct: 0.50

## 4. 執行時程

| 週次 | 工作 | 驗收標準 |
|---|---|---|
| W1 | 改參數（階段 A）＋閘門以 `log only` 模式上線 | ptss 計算與重建一致；每日訊號快照落地 |
| W1–W2 | 加入成本/滑價/資金費率記錄 | 每日可產出 PnL 報表 |
| W2–W4 | 紙上驗證 4 個換倉週期 | 換倉時間正確（週四 00:05 UTC）；週費用 < 0.2% |
| W3 | A/B 測試：00:05 vs 08:05 UTC、K 4 vs 5 | 至少 2 週資料再定案 |
| W5 | 小額實盤（10–20% 資金） | 熔斷規則生效；實際滑價 ≤ 3bp |
| M2–M3 | 檢視實際 vs 回測 | 月報酬差距 < 2pp；Sharpe > 1.0 |
| M3+ | 資金放大、考慮積極版軟閘門 | 連續 3 個月符合預期 |

## 5. 監控與預警

| 指標 | 綠燈 | 黃燈 | 紅燈（動作） |
|---|---|---|---|

| 實際 vs 回測 | < 2pp/月 | 2–4pp | > 4pp（全面檢視執行面） |

## 6. 不建議做的事（已實測排除，勿再嘗試）

| 方法 | 實測結果 | 原因 |
|---|---|---|
| 每日換倉 | −76.4% | 成本 |
| 個幣停損/停利 | −6% ~ −9% | 噪音掃出、切斷趨勢 |
| 投資組合波動目標 | 無增益 | 與閘門功能重疊且破壞加減倉一致性 |
| 回撤節流（−10% 降 0.6×） | 16.9% → 9.4% | 賣在低點 |
| 反向下單（風險關閉翻轉部位） | OOS 14.9% / Sharpe 0.84 | 無反向 edge，週轉加倍 |
| 順勢一致性過濾 | OOS 10.9% / 0.70 | 過度限制選股空間 |
| 資金費率進場過濾 | 樣本內大幅變差 | 疑似過擬合 |
| 低分散度縮倉 | 13.2% | 縮在最好的時候 |
