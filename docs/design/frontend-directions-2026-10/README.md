# 前端風格方向 — 2026-10

同一畫面（CoinFull Prime 排行）的四種視覺語言。四份稿的內容、資料、欄位完全一致，只改設計語言，方便直接比較。皆為 1600×1000 靜態示意，尚未處理響應式與互動狀態。

| # | 方向 | 一句話 | 適合 | 代價 |
|---|---|---|---|---|

## 設計要點

### A — 黑曜終端
- 色：`#050607` 底、`#090b0e` 面板、`#191e25` 線、`#ffb224` 琥珀、`#5ad1e6` 多、`#2fbf8b` / `#ff5d5d` 損益
- 字：Noto Sans CJK TC（介面）+ Noto Sans Mono（所有數字、標籤）
- 形：0–2px 圓角、無陰影、區塊以 1px 線切分；多空以左側 2px 色條 + 文字標記
- 判斷：最適合這個產品。把裝飾全部拿掉後，密度與層級反而更清楚

### B — 紙本帳房
- 色：`#f5f1e8` 紙、`#171410` 墨、`#d9d0be` 規線、`#b8402a` 朱紅
- 字：Noto Serif CJK TC（標題/代號）+ Noto Sans Mono（數字）
- 形：無卡片、無圓角、以水平規線與欄位對齊建立秩序
- 判斷：辨識度最高，但不適合盯著盤面操作；可作為「研究 / 報表」第二主題

### C — 極光玻璃
- 色：`#070a12` 底、`rgba(19,25,40,.72)` 玻璃、`#7c95ff` 主色、`#4fd8e8` 次色
- 字：Inter + Noto Sans CJK TC + JetBrains Mono
- 形：14px 圓角、內高光、柔和陰影、bento 版面、膠囊分隔控制
- 判斷：現有風格的收斂版。若只能做低風險改版，選這個

### D — 訊號看板
- 色：`#e7e7e2` 底、`#0e0e0e` 墨、`#ff4d00` 安全橘、`#ffe500` 警示黃
- 字：Noto Sans CJK TC；英文標籤全大寫 + 字距；數字等寬
- 形：1–2px 黑框、零圓角、黑底表頭、左側 4px 多空色條、排程列加危險條紋
- 判斷：把「風險」變成視覺語言，但日常操作會疲勞；適合獨立的风控/告警頁

## 建議

1. **主方向選 A**，吸收 C 的卡片資訊層級（bento 只用於總覽，不用於表格）。
2. **B 保留為第二主題**（研究 / 列印報表），不要與 A 混用在同一畫面。
3. **D 只用在風控與緊急狀態**，例如 API 斷線、保證金不足、排程失敗。

若目標是「一週內看到明顯不同」，選 C 並把紫色 accent 換成藍/青、圓角收斂到 10–12px，風險最低。
