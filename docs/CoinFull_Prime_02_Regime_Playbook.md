# CoinFull Prime 最適用情境（市場狀態手冊）

*文件編號：02｜日期：2026-09-16｜附 2026-09-16 即時快照*

---

## 1. 風險分數（pts）：本策略的單一儀表

```
pts(t) = [ BTC 收盤 > BTC 50 日 SMA ]            # 趨勢
       + [ 宇宙中站上 50 日 SMA 的比例 > 30% ]    # 廣度
       + [ 全市場資金費率（252 日百分位）> 45 ]   # 情緒/擁擠度
```

* 狀態分布（2021–2026.07）：pts=0 **37.2%**、pts=1 15.6%、pts=2 18.3%、pts=3 28.9%。
* 風險關閉（pts=0）：5.4 年 96 次，約 **17.2 次/年**，平均持續約 10 天。
* 計算頻率：每日一次（換倉前必須計算；建議每日收盤後都算，用於監控）。

---

## 2. 各狀態的策略表現（v2 + 建議參數）

| 狀態 | 樣本內年化（2021–23） | 樣本外年化（2024–26.07） | 建議動作 |
|---|---|---|---|
| **pts = 0** | +4.2% | **−42.8%（Sharpe −2.2）** | **平倉、停止下單** |
| **pts = 1** | +37.8% | +20.5% | 正常運作（1.0×） |
| **pts = 2** | **+94.5%** | **+75.1%（Sharpe 4.5）** | **最佳情境：資金費率百分位 ≥ 45 時可加碼至 1.15–1.2×** |
| **pts = 3** | −2.7% | +45.6%（Sharpe 2.0） | 正常運作，但**不加碼**（樣本內外不一致） |

> pts=3 是「趨勢＋廣度＋情緒全滿」＝過熱訊號；樣本內 −2.7% 顯示追高危險，樣本外雖正但不加碼是最穩健選擇。

## 4. 適用 / 不適用總結

**✅ 最適用**
1. 趨勢明確且廣度足夠（pts=2）：樣本內 +94.5%、樣本外 +75.1%，Sharpe 4.5。
2. 資金費率不擁擠（百分位 45–80）：策略是淨收費方。
3. 橫斷面分化大：多空兩端都有明確強弱差異。
4. 2021、2024 型的「多頭＋高分化」市場：+100.4%、+45.4%。

**⛔ 不適用**
1. **pts=0**：低波動、無方向、資金費率低迷 → 樣本外 −42.8%/yr（約 17 次/年，必須停手）。
2. BTC 30 日跌幅 < −8% 的崩跌段（−13.2%/yr）。
3. 極端擁擠（資金費率百分位 > 90）。
4. 低波動盤整、無分化市場（alpha 不足、成本相對變重）。
5. 明顯的「日內反轉」市場（1 日動能反轉）：策略原型會吃虧，需靠 7/30 日成分緩解。

## 5. 即時狀態快照（2026-09-16）

| 指標 | 數值 | 判定 |
|---|---|---|
| BTC 收盤 | 75,417.7 | — |
| BTC 對 50 日 SMA | **+4.87%** | 趨勢 ✅ |
| 廣度（8 檔主流幣站上 50 日 SMA） | **88%** | 廣度 ✅ |
| 市場資金費率百分位 | **29%** | 情緒 ❌ |
| **pts** | **2 / 3** | **可運作（次佳情境）** |
| 市場資金費率 | +0.0022% / 日（百分位 29；p10/50/90 = −0.0145/+0.0130/+0.0695） | 不擁擠，但**收費偏低**（< 45） |
| BTC 14 日年化波動 | 38% | 偏高 |
| BTC 7 日 / 30 日報酬 | −4.0% / +17.5% | 短線回檔、月線仍多 |
| BTC 自 60 日高點 | −16.9% | 中度回檔 |

**建議動作**：維持 **1.0×** 部位、正常運作，但**暫不加碼**。
理由：加碼條件為「資金費率百分位 45–80」，目前僅 **29**；歷史上資金費率百分位 < 45 的期間策略明顯偏弱（−3.6% ~ −18.3%/年）。本次屬「趨勢＋廣度」型 pts=2（資金費率條件未過），以 1.0× 運行即可。留意波動 38% 與 7 日轉負，若 `pts` 掉到 0 則立即平倉停單。

## 6. 狀態轉換的處理原則

| 轉換 | 動作 | 依據 |
|---|---|---|
| pts ≥1 → 0 | **當日平倉、停止下單** | OOS Sharpe 0.84 → 1.94 |
| pts 0 → ≥1 | 正常換倉日重建部位；可延後 1 日進場 | 延遲進場 Sharpe 1.43、回撤 −11.7% |
| pts 1 → 2 | 可加碼至 1.15–1.2×；**若資金費率百分位 < 45（只有趨勢＋廣度）則維持 1.0×** | 樣本內外皆最佳；資金費率偏低的期間較弱 |
| pts 2 → 3 | 回落到 1.0×，不加碼 | 樣本內 −2.7% |
| 換倉日遇 BTC ≤ −5% | 延後 24 小時 | Sharpe 1.45 |
| 連續處於 pts=0 超過 45 天 | 檢視參數是否失效（可能市場結構改變） | — |

## 7. 一句話版本

> **趨勢在、廣度在、不擁擠 → 全力做；三者只剩一個或全無 → 平倉休息。**
> 不要在風險關閉時反向押注（實測樣本外更差），也不要在過熱時加碼。
