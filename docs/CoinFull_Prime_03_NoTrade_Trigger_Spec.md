## 2. 觸發規則規格（可直接實作）

### T1｜風險關閉停單（核心，優先實作）

| 項目 | 內容 |
|---|---|
| 觸發條件 | `pts == 0`（BTC ≤ 50MA、廣度 ≤ 30%、資金費率百分位 ≤ 45） |
| 動作 | 於下一個換倉時點**平掉所有部位**（reduce-only），並在狀態恢復前**不開新倉** |
| 解除條件 | `pts >= 1`（若採延遲進場：恢復後第 2 日才建倉） |
| 檢查頻率 | 每日計算；實際下單僅在排定換倉日（週四）與解除日 |
| 預期效益 | OOS Sharpe 0.84 → 1.94；年化 14.9% → 25.1%；回撤 −20.6% → −9.8% |
| 邊界 | 若在非換倉日轉為 pts=0，允許「提前平倉」（保守版）或等到下一次換倉（積極版，較少週轉） |

### T2｜崩跌日延後換倉

| 項目 | 內容 |
|---|---|
| 觸發條件 | 換倉當日（或前一日）BTC 24 小時報酬 ≤ **−5%** |
| 動作 | 換倉延後 **24 小時**，於次日同時段執行 |
| 上限 | 最多連續延後 2 次（避免無限期拖延） |
| 預期效益 | 全期 18.8% → **19.2%**、Sharpe 1.41 → **1.45**，回撤不變 |
| 注意 | 若同時 pts=0，則以 T1（平倉）優先 |

### T3｜延遲進場（可選）

| 項目 | 內容 |
|---|---|
| 觸發條件 | `pts` 由 0 恢復為 ≥ 1 |
| 動作 | 不當日建倉，延後 1 日 |
| 預期效益 | Sharpe 1.43（vs 1.41）；回撤 −15.3% → −11.7% |
| 取捨 | 年化略降（19.0% → 18.7%），換取較平滑的權益曲線 |

### T4｜延遲平倉（可選，與 T3 二選一）

| 項目 | 內容 |
|---|---|
| 觸發條件 | `pts` 由 ≥ 1 轉為 0 |
| 動作 | 延後 1 日再平倉 |
| 預期效益 | 回撤 −15.3% → −11.7%；樣本外 23.2% / Sharpe 1.71 |
| 風險 | 落後指標可能加劇單日虧損；若該日 BTC 跌幅 > 5% 應立即平倉（不延遲） |

### T5｜極端擁擠保護（防禦性）

| 項目 | 內容 |
|---|---|
| 觸發條件 | 市場資金費率百分位 > 90 |
| 動作 | 維持現有部位，但**禁止加碼**；若百分位 > 95 且 pts ≤ 1，則減半 |
| 依據 | 極端擁擠時多空雙方都可能被擠壓；此規則保守、影響小 |

### T6｜熔斷（營運層，非策略層）

| 觸發條件 | 動作 |
|---|---|
| 單日策略虧損 ≤ −3% | 當日停止所有下單 |
| 累積回撤 ≤ −12% | 部位降至 0.5× |
| 累積回撤 ≤ −18% | 全部平倉並停機，人工檢視 |
| API 連續錯誤 / 資料缺漏 | 停止下單並告警 |

## 3. 每日檢查流程（偽程式碼）

```python
def daily_check(now, state):
    # 1. 計算風險分數（用已收盤的日線，避免未完成 K 線）
    pts = regime_pts(btc_daily_closed, universe_daily_closed, funding_history)

    # 2. 熔斷優先
    if state.drawdown <= -0.18:   return "STOP_ALL"
    if state.drawdown <= -0.12:   state.scale = 0.5

    # 3. 風險關閉 → 平倉且停單
    if pts == 0:
        return "FLATTEN_NO_TRADE"

    # 4. 是否為換倉日（每週四 UTC 00:05）
    if not is_rebalance_day(now): return "HOLD"

    # 5. 崩跌日延後
    if btc_ret_1d <= -0.05 and state.defer_count < 2:
        state.defer_count += 1
        return "DEFER_24H"

    # 6. 恢復後延遲進場（可選）
    if state.prev_pts == 0 and state.days_since_risk_on < 1:
        return "WAIT_ONE_DAY"

    return "REBALANCE"
```

## 4. 參數與門檻來源

| 門檻 | 值 | 來源 |
|---|---|---|
| 趨勢門檻 | BTC > 50 日 SMA | 使風險分數具區辨力（最大單一因子） |
| 廣度門檻 | 30% | 與趨勢門檻組合後，pts 分層的樣本外差距最大 |
| 資金費率百分位門檻 | 45（252 日） | 同 6.2 表：門檻 45 時 pts=2 樣本外 Sharpe 4.5 |
| 崩跌門檻 | −5% | 5.4 年間可觸發約 20–30 次，屬「罕見但不罕見到無感」 |
| 延後上限 | 2 次 | 避免極端行情下無限期延後（錯過反彈） |

> 提醒：門檻（45、30%、50 日）是經樣本內外檢驗後選定的，但仍是歷史最佳化結果；上線後應以「落在門檻附近 ±10% 也不會劇變」的方式監控穩健性。實測敏感度：廣度門檻 20/25/30% 的差異皆在可接受範圍。
